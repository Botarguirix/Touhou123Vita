## Aplicación inmediata

1. Mantener el camino actual de reconstrucción nativa en C como baseline funcional y no reemplazarlo por un dynarec especulativo.
2. Añadir un pipeline de análisis reproducible para el PE local fijado por SHA: desensamblado, límites de función candidatos, llamadas/ramas, reachability desde entradas conocidas, cobertura de mnemonics y lista fail-loud de lo no soportado. Mantener artefactos grandes/locales fuera de Git.
3. Usar lifting estático primero en una vertical acotada del motor original (por ejemplo, input matcher y dispatcher de acciones), contrastar vectores con ejecución x86 y portar a C solo con evidencia. Mantener el gate actual hasta que los contratos de matcher y los replays lo sustituyan.
4. Mantener la reconstrucción nativa como baseline. Evaluar en una rama de investigación si el loader/dynarec de Touhou75 puede cargar el PE local de TH123 y registrar el primer import no soportado; no sustituir la demo actual hasta que supere selección, combate y regresión en Vita3K/hardware. Las funciones/estructuras del motor compartido sirven para priorizar búsquedas, pero cada contrato debe contrastarse con el PE 12.3.
5. Comparar las llamadas D3D8 del TH123 con el puente/raster de Touhou75 antes de portar cualquier implementación. Si coinciden, extraer primero vectores de entrada/salida y adaptar bajo sus avisos de licencia; la mejora de FPS requiere un backend GPU que Touhou75 aún no tiene.
6. Perfilar en Vita3K/hardware antes de decidir optimizaciones nativas; documentar coste, mejora y fallback por función.

## Evidencia del matcher x86 local

La herramienta [x86_motion_oracle.py](../tools/x86_motion_oracle.py) ejecuta `0046cc90` del ejecutable 1.10a fijado. Construye snapshots sintéticos de 90 muestras en bloques de 8 y neutraliza solo los asserts/stack-cookie externos. La suite diferencial [test_input_arm_oracle.py](../tools/test_input_arm_oracle.py) compara ese x86 con `src/input.c` compilado ARMv7: 17 vectores contractuales y 384 secuencias generadas pasan. Sigue sin modelar el productor por tick ni bindings configurados, por lo que la paridad del matcher no prueba el gameplay completo.

Comando local (requiere el PE propio y las dependencias Python locales):

```powershell
python tools/x86_motion_oracle.py original/th123.exe artifacts/x86-motion-vectors.csv
```

El artefacto con secuencias y resultados se genera localmente y permanece ignorado por Git junto con el ejecutable.
